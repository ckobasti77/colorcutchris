# Referentni snimci — dfrajlica (javni wizard)

Snimci javnog birača termina sa https://dfrajlica.vercel.app (desktop 1440 i mobilni 390), napravljeni skriptom
`scripts/ref-shots.mjs` bez slanja zahteva. Služe samo kao referenca za **raspored i tok** (koraci, nedeljna traka,
slotovi, forma, greške) — boje, fontovi i tekst su namerno drugačiji na našem sajtu.
Admin panel nije snimljen; njegov raspored je preuzet iz koda reference (`app/admin/*`).
